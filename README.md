## Projetos

### RiJoy
API para uma plataforma de e-commerce desenvolvida com foco em boas práticas de back-end. O projeto integra armazenamento de imagens em nuvem para produtos e conta com uma rotina (em desenvolvimento) para redimensionamento automático de imagens, visando otimizar desempenho e reduzir custos de armazenamento.

### SertaoGen
Aplicação desenvolvida durante o hackathon da ExpoAgro Crateús 2026, com foco em análise preditiva voltada à fertilidade e ao manejo de animais. O projeto envolveu o desenvolvimento de uma solução para apoiar a tomada de decisão no contexto do produtor rural.
